# Credits

ALFinity stands on the shoulders of mathematicians who explored these shapes long before
computers could draw them, and was built with the help of modern tools.

## Mathematicians

### [Pierre Fatou](https://en.wikipedia.org/wiki/Pierre_Fatou) (1878–1929)

French mathematician who, from 1917 on, studied what happens when a function is applied to
complex numbers again and again – the groundwork for Julia sets.

### [Gaston Julia](https://en.wikipedia.org/wiki/Gaston_Julia) (1893–1978)

French mathematician whose prize-winning 1918 paper on the same question made him famous.
The Julia sets carry his name – decades before anyone could see them on a screen.

### [Benoît B. Mandelbrot](https://en.wikipedia.org/wiki/Benoit_Mandelbrot) (1924–2010)

Mathematician who coined the word "fractal" in 1975 and showed how common fractal shapes are
in nature. Working at IBM, he used computers to draw and study the set that now bears his
name (1980) and made it world-famous.

### [Adrien Douady](https://en.wikipedia.org/wiki/Adrien_Douady) (1935–2006) and [John H. Hubbard](https://en.wikipedia.org/wiki/John_H._Hubbard) (born 1945)

They gave the Mandelbrot set its name, proved in 1982 that it is connected – all in one
piece – and laid the foundations for understanding its structure.

## Tools

### [GitHub Spec Kit](https://github.com/github/spec-kit)

A toolkit for spec-driven development: every feature of ALFinity was first written down as a
specification, a plan and a task list, and only then built.

### [Claude Code](https://claude.com/claude-code) with [Claude](https://www.anthropic.com/claude) by Anthropic

The AI coding assistant (with the model Claude Opus 5.5) that helped write the
specifications, the code, the tests and these texts.

### [GitHub Pages](https://pages.github.com)

Hosts ALFinity for free, straight from the source code repository.
